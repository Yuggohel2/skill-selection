# Example: Hackathon AI Voice Assistant

This is a sample manifest generated by `/skill-selection` for a 24-hour
hackathon project building a real-time AI voice assistant with a web dashboard.

## Context

- **Project:** Real-time AI voice assistant with web UI
- **Stack:** Next.js + Tailwind + Supabase + Gemini Multimodal Live API
- **Context:** 24-hour hackathon — speed over perfection
- **Demo format:** Live browser demo with voice interaction

## Result

With 21 skills suppressed, the agent:
- Generates zero conflicting CSS (single design authority)
- Writes no test scaffolding (all time goes to features)
- Never loads irrelevant skill instructions into context
- Produces focused, consistent output in every response
